# data/

This folder is populated automatically when you run the notebooks.

Generated files:
- iris_raw.csv          → Raw Iris dataset
- iris_pca.csv          → PCA 2D reduced data
- iris_tsne.csv         → t-SNE 2D reduced data
- pca_scree_plot.png    → Scree + cumulative variance plot
- pca_2d_plot.png       → PCA scatter plot
- pca_loadings.png      → Feature loadings bar chart
- tsne_plot.png         → t-SNE scatter plot
- tsne_perplexity_comparison.png → Perplexity effect grid
- pca_vs_tsne.png       → Side-by-side comparison
